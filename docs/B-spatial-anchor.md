# Section B: Spatial Anchor & Placement System

## B1. Spatial Anchor

A Spatial Anchor defines where MR content appears in the real world.

- Content remains fixed in position  
- Moves relative to your environment  

In-app appearance:
- Rectangular frame  
- Corner strokes  
- Logo and instruction text

## B2. Placement System (2-Point System)

### B2.1 How It Works

- Point 1 → Center (pivot)  
- Point 2 → Orientation (north direction)  

---

### B2.2 Example

- Point 1 in front + Point 2 above  
→ Upright (north away from you)

- Point 1 in front + Point 2 below  
→ Upside down (north toward you)

Key Insight:
- Point 2 controls orientation  

---

### B2.3 Best Practice

- Mark both points physically  
- Ensures consistent setup  

---

### B2.4 Adjusting Anchor

- Use Grip button to move  
- UI menu:
  - Height  
  - Rotation  
  - Position  

---

### B2.5 Multiplayer Note

- Avoid excessive adjustment  
- Prevents desynchronization
