## A5. Configure General Settings
Go to Settings → General:

- Enable Unknown Sources  
- Set Meta Horizon as active (OpenXR Runtime)

## A6. Enable Developer Features
Go to Settings → Developer:

- Enable Developer Runtime Features
- Enable Passthrough over Meta Horizon LinK

## A8. Verify Connection
- Wear headset  
- Confirm white ceiling and floor environment with gridlines
