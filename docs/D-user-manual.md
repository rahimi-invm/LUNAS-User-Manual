# Section D: LUNAS App User Manual

## D1. Basic Interaction

- Use Trigger button to interact  

---

## D2. Wrist Menu

1. Hold both controllers  
2. Raise left controller  
3. Face wrist toward you  

- Menu / Settings button appears  

4. Use right controller + trigger  

---

## D3. Re-anchor

- Found in Settings  

Use when:
- Content misaligned  

Function:
- Reset anchor placement  

Best Practice:
- Use instead of manual adjustment
