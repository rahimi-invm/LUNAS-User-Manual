# Section E: Troubleshooting

## E1. No Content in Headset

Cause:
- Not connected  

Fix:
1. Close app  
2. Ensure Meta Horizon Link running  
3. Reconnect headset  
4. Confirm white grid  
5. Relaunch  

---

## E2. Cannot Connect

### Restart Meta Horizon Link
Settings → General → Restart  

### Restart OVRService
CTRL + SHIFT + ESC  
Services → OVRService → Restart  

### Restart Laptop
If needed  

---

## E3. Lag / Not Smooth

Cause:
- Weak connection  

Fix:
- Use Link Cable instead of Air Link
