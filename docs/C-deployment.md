# Section C: Deploying the Application

## C1. Prepare Application
- Download and extract LUNAS VR app  

## C2. Prepare System
- Meta Horizon Link running  
- Headset powered on and paired  

## C3. Connect Headset
- Air Link or Link Cable  

## C4. Verify Connection
- White grid environment visible  

## C5. Launch App
- Run app on laptop  

## C6. Load into App
- Wear headset  
- App loads  

## C7. Anchor Placement

Instruction:
"Air Pinch toward the floor to set the Position of the Anchor"

## C8. Place Point 1
- Point at floor  
- Press Trigger  

## C9. Place Point 2
- Define orientation  

## C10. Anchor Appears
- Observe placement  

## C11. Adjust (Optional)
- Grip button / UI  

## C12. Confirm
- Press Confirm  

## C13. Start
- Content appears
