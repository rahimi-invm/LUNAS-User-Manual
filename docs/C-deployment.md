# Section C: Deploying the Application

## C1. Prepare Application
- Download and extract LUNAS VR app  

## C2. Prepare System
- Meta Horizon Link on laptop running  
- Headset powered on and paired  

## C3. Connect Headset
- Air Link or Link Cable [refer to Section A7](docs/A-first-time-setup.md/#A7-Connect-Headset-to-Laptop)

## C4. Verify Connection
- White floor and ceiling with gridlines environment visible  

## C5. Launch App
- If 1st time, run app on laptop  
- After the initial run, the app should be appeared in Library
    - Feel free to wear the headset and launch the app from the Library

- In the headset, the visual should've changed with some animation and Meta logo
- You will know the app is loaded if the camera passthrough is on and you can see your surrounding with some UI window floatin infront of you 

## C7. Anchor Placement

- There will be a UI window appeared with Instruction:
    >"Air Pinch toward the floor to set the Position of the Anchor"

- Place Point 1
    - Point at floor  
    - Press Trigger
    - A dot will appear  

- Place Point 2
    - Point at floor above point 1
    - You should see the a straight line from point 1
    - Press Trigger

- Both points should disappear, and a Spatial Anchor should appear.


## C9. Adjusting Anchor (optional)
If you are not happy with the placement, you can adjust using the following method
- Use Grip button to manually grab the spatial anchor and move it
- Use fine tune features, there will be a UI menu appear to adjust:
  - Altitude/Height (Up, down) 
  - Rotation/Yaw (Clockwise, Counter-clockwise) 
  - Lateral (Forward, Backward, Left, Right)

## C12. Finalizing the Spatial Anchor
- Confirm placement once you satisfied
- The content will appear
- You can now use the application
