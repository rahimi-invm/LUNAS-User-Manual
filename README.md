# LUNAS VR – Setup & Operation Guide

This repository contains the setup and operational documentation for the LUNAS VR application.

## Overview

This guide covers:
- First-time Meta Quest setup
- System configuration
- Application deployment
- Spatial anchor placement
- User interaction
- Troubleshooting

## Prerequisites

- A laptop (VR-ready recommended)
- Meta Quest 3 headset
- Meta Horizon mobile app
- Meta Horizon Link (installed on laptop)
- Meta Horizon account
- LUNAS App
